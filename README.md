# CSCA 学习站

Сайт для подготовки к CSCA: китайская лексика (карточки с интервальным повторением), теория по математике, физике и техническому китайскому на китайском, тренировка теории, задачи в формате CSCA, чтение условий и пробный экзамен с таймером.

Работает без сервера и без сборки: просто статичные файлы.

## Как выложить на GitHub Pages

1. Создайте на github.com новый публичный репозиторий, например `csca`.
2. Нажмите **Add file → Upload files** и перетащите всё содержимое этой папки: `index.html`, `style.css`, `app.js`, папку `data` (папку `build` можно не загружать). Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите *Source: Deploy from a branch*, ветку `main`, папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/csca/`.

Локально сайт открывается двойным щелчком по `index.html`.

## Структура

- `data/vocab.js` — словарь (695 слов): колоды «Язык условий», «Математика», «Физика», «Китайский».
- `data/theory.js` — теория по темам: формулировки на китайском, перевод, ключевой термин.
- `data/tasks.js` — тренировочные задачи (`TASKS_BASE`, `TASKS_EXTRA`), тексты для чтения (`PASSAGES`, `READING`).
- `data/real.js` — 518 заданий реальных экзаменов CSCA (математика 2025-12, 2026-01/03/04/06; 理科中文 2025-12, 2026-01/03/04). Восьмое поле — источник «дата·номер».
- `data/konspekt_m.js`, `konspekt_p.js`, `konspekt_l.js` — конспект на русском по всем темам.
- `build/build_data.py` — пересборка `vocab.js` и `tasks.js` из исходных списков (нужен `pypinyin`).

Добавить задачу: допишите в `build/tasks_base.js` (или прямо в `data/tasks.js`) строку
`['m', 'тема', 'условие', ['верный ответ', 'неверный', 'неверный', 'неверный'], 'перевод', 'разбор']`.
Первый вариант всегда верный — на сайте варианты перемешиваются. Дробь записывается как `[[a|b]]`.

Прогресс хранится в браузере (localStorage). Перенести его на другое устройство можно кнопками внизу страницы.
